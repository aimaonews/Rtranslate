# TransVerse 译境 — UI/UX 审查报告与设计方案

> 阶段一产出。审查方法：真实浏览器（Edge）渲染全部 9 个界面截图 15 张 + CDP 程序化视觉检测
>（对比度/溢出/控件尺寸/圆角与字号分布）+ 全部样式源码盘点。
> 说明：visual-judge 子代理因供应商不可用（GLM-5.3-Flash provider-not-found）未能启动，
> 本报告以程序化测量 + 代码审查代替人工看图评审。

---

## 1. 现状盘点

**技术栈**：MV3 扩展，Vite + TypeScript，原生 TS + 手写 CSS（无框架）。
**界面清单**：

| 界面 | 文件 | 状态覆盖 |
|---|---|---|
| 弹窗 popup | src/popup/ | 正常/不可用页面/翻译中/已翻译 |
| 设置页（10 标签） | src/options/ | 各标签表单态 |
| 闪卡复习 | src/review/ | 空态/有卡/评分/完成 |
| 文档翻译 | src/files/ | 初始/进度/完成/失败 |
| 页面注入 UI | public/content.css | 悬浮球/划词气泡/译文/加载/错误/字幕面板/生词高亮 |

**样式体系现状**：4 个页面 CSS 各自定义一套同名变量（--tv-primary 等），值大体一致但无共享来源；
content.css 独立一套。无共享 tokens 文件、无公共组件库（按钮/输入框/开关在各页重复实现且细节有差异）。

## 2. 实测发现的问题（按严重度）

### P0 — 对比度系统性不达标（WCAG AA）
品牌蓝 #409EFF 在白底上对比度仅 **2.78:1**（AA 需 4.5:1），实测命中：
- popup：主按钮白字 on 蓝底 2.78、"文档翻译/开始复习"描边按钮蓝字 2.78、by AIMAO 链接 4.32
- options：导航激活文字、标签 tag、"添加"按钮、field-static 蓝字全部 2.78
- files："点击选择文件"链接、"开始翻译"按钮 2.78
- review：品牌名 4.20

**根因**：#409EFF 是"填充色"不是"文字色"。Element UI 同款色也存在此问题，但专业交付必须修。

### P1 — 字号体系混乱
实测同时存在 10/11/12/12.5/13/13.333/13.5/14/14.5/15/17/19/21/28/34/44px 共 16 种字号，
其中 13.333px（浏览器默认）出现在各页面——说明有元素漏设字号。缺统一字阶。

### P1 — 圆角不统一
options 内 8/9/12/999px 混用；译文样式页出现 11px/2px 异类；popup 有 5/6/8/10/12px。
缺统一圆角尺度。

### P1 — 控件尺寸偏小
开关 21px 高、原生 radio/checkbox 13px——低于桌面端舒适操控尺寸（建议 ≥22px / 16px）。

### P2 — 结构层面
- 各页面重复实现按钮/开关/输入框，细节有差异（如 popup 开关与 options 开关样式不同源）
- popup 状态区信息层级弱（状态文本与大按钮之间缺视觉锚点）
- review 空态只有文字，无视觉焦点
- 划词气泡按钮区 6 个按钮平铺，信息密度高、主次不分
- 无统一焦点环规范（仅 popup 定义了 focus-visible）

## 3. 视觉方向决策

**保持 AIMAO 品牌蓝 #409EFF 为主色**（用户明确要求与主站一致），但按用途分级：

| 用途 | 色值 | 对比度 | 场景 |
|---|---|---|---|
| 品牌填充/激活背景 | #409EFF | — | 主按钮底、开关开态、焦点环、图标 |
| 文字级蓝（链接/标签/描边按钮文字） | #2B6CB0 | 5.9:1 ✓ | 一切蓝色文字 |
| 主按钮文字反白底 | #337ECC | 3.9:1（粗体大字合规） | 主按钮 hover/默认底 |
| 浅蓝底 | #ECF5FF | — | 选中态、提示卡片 |

**风格定位**：Element 式扁平工具风（与主站一致）——干净、克制、信息密度适中；
不引入渐变滥用/毛玻璃/装饰性标签。唯一"记忆点"放在译文样式系统（12 种样式本身即是产品特色）。

## 4. 设计系统方案（阶段二实施）

### 4.1 全局 tokens（新建 src/shared/ui/tokens.css，四页面 + content 共用）

```
--tv-primary: #409eff        /* 品牌填充 */
--tv-primary-strong: #337ecc /* 主按钮底/hover */
--tv-primary-text: #2b6cb0   /* 文字级蓝（AA） */
--tv-primary-soft: #ecf5ff
--tv-text: #1e293b / --tv-text-sub: #64748b / --tv-text-faint: #94a3b8
--tv-bg: #f7f9fa / --tv-card: #fff / --tv-border: #e4e7ed
--tv-danger: #f56c6c / --tv-warning: #e6a23c / --tv-success: #67c23a
字阶: 12 辅助 / 13 次要 / 14 正文 / 15 卡片标题 / 21 页标题 / 28 展示数字
圆角: 6 小控件 / 10 输入按钮 / 14 卡片 / 999 胶囊
间距: 4/8/12/16/24/32
阴影: sm 0 1px 3px rgba(15,23,42,.06) / md 0 4px 12px rgba(15,23,42,.08) / lg 0 10px 32px rgba(15,23,42,.14)
动效: 150ms ease 颜色态 / 200ms 结构态 / 尊重 prefers-reduced-motion
焦点环: 2px solid var(--tv-primary), offset 2px（全控件统一）
```

### 4.2 组件规范
- **按钮**：三级——primary（蓝底白字）/ secondary（白底蓝字蓝边）/ ghost（无边文字按钮）；高度 32px（弹窗 34px）；禁用 opacity .5
- **开关**：40×22，knob 18px
- **输入/下拉**：高 32px，radius 10，hover 边蓝，focus 边蓝+浅蓝环
- **radio/checkbox**：16px，选中蓝底白勾
- **卡片**：白底、border 1px、radius 14、shadow sm、padding 18/22
- **标签 tag**：浅蓝底 + 文字蓝（#2b6cb0）
- **空态**：图标（SVG 线性）+ 一句说明 + 主行动按钮
- **加载**：spinner（品牌蓝）+ 骨架屏用于列表
- **错误**：danger 色 + 重试按钮 + 具体原因文案

### 4.3 页面改进计划
1. **tokens 落地**：四页面 CSS 改为 import 共享 tokens；删除各自重定义
2. **popup**：状态区重构——状态点（彩色圆点+文字）+ 大按钮；控制区行距收紧；footer 双按钮改 secondary
3. **options**：导航激活态对比度修复；表单行统一 44px 行高；tag 文字色修复；radio 卡片网格对齐
4. **review**：空态加 SVG 图标；卡片翻转保留；评分按钮色板已合规（语义色），统一高度 44px
5. **files**：上传区视觉强化（虚线框+图标+主次文案层级）；"点击选择文件"改文字蓝；进度条品牌蓝
6. **content.css**：气泡按钮区分主次（主操作 primary，其余 ghost）；悬浮球阴影统一；字幕面板微调圆角/阴影
7. **焦点与动效**：全控件 focus-visible 环；reduced-motion 媒体查询

### 4.4 回归风险与对策
| 风险 | 对策 |
|---|---|
| 改类名破坏 TS 引用 | 只改 CSS 值与结构最小改动；必须改结构时同步改 TS 并全文 grep 类名 |
| content.css 注入页面样式被宿主覆盖 | 保持 !important 策略不变；改后 e2e 重验划词气泡/悬浮球/译文 |
| 字号收敛导致文本截断 | 截断检测纳入验收（lint 脚本重跑） |
| 开关/按钮尺寸变化导致布局错位 | 截图对比验收 |
| 测试回归 | vitest 288 全绿 + e2e 六阶段重跑 |
