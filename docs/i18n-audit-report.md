## 一、品牌名「AI猫」的全部出现点（问题 1）

「AI猫」共 **6 处代码定义 + 2 处派生文案**，分布在 4 个文件。任何一处改为「aimao」都需要同步检查其余位置，否则同一界面会出现两种叫法。

| # | 文件:行 | 内容 | 呈现位置 |
|---|---|---|---|
| 1 | `src/background/engines/aimao.ts:11` | `name: 'AI猫'` | 引擎注册名（background 内部，可能透出到错误信息/日志） |
| 2 | `src/options/main.ts:650` | `{ id: 'aimao', name: 'AI猫', desc: 'AI猫是本站提供的 OpenAI 兼容翻译服务，开箱即用。' }` | 设置页引擎下拉选项 + 选中后的说明文字（用户截图 1） |
| 3 | `src/popup/main.ts:97` | `{ id: 'aimao', name: 'AI猫' }` | popup 引擎下拉（用户截图中 popup 的引擎选择器同样显示「AI猫」） |
| 4 | `src/onboarding/main.ts:43` | `{ id: 'aimao', name: 'AI猫' }` | 首次安装引导页的引擎选择步骤 |
| 5 | `src/options/main.ts:413` | `'AI猫 aimao.today'` | 设置页左侧栏底部外链文字（**全部 12 个 tab 都可见**，本次动态取证每个 tab 的中文残留第 1 行都是它） |
| 6 | `src/options/main.ts:895` | `'粘贴 AI猫 API Key'` | 设置页 API Key 输入框 placeholder |
| 7 | `src/options/main.ts:898` | `'获取API秘钥'` | API Key 右侧外链文字（另注：「秘钥」为错别字，规范写法为「密钥」） |
| 8 | 引擎下拉的其他选项名 | `谷歌免费` / `微软免费` / `MyMemory 免费` / `OpenAI 兼容`（popup:98-102 与 options 同款列表） | 与「AI猫」同属引擎显示名体系，改品牌名时需同表处理 |

说明：`docs/store-listing/` 与 `public/_locales/` 的商店文案里也含「AI猫」，属于商店元数据，不在本次扩展内 UI 范围，但改名时需一并核对。

## 三、按钮文案溢出测量（问题 3）

### 3.1 划词气泡（实锤，全语言受影响）

气泡为**定宽 406px、6 个按钮、按钮固定高 26px、`white-space: normal`、12px 字号**。对 5 种界面语言的实测（`docs/audit-shots/audit-data.json` / `audit-data2.json`）：

| 界面语言 | 6 按钮中换行数 | 垂直溢出（文字高出按钮框） | 最严重样例 |
|---|---|---|---|
| 法文 fr | 4 | 4 个按钮 scrollH 28–36px > 框高 26px | `Lire à voix haute` 折成 **3 行** |
| 德文 de | 3 | — | `Vorlesen`（Read aloud 的德语）2 行 |
| 葡文 pt-BR | 4 | — | `Ler em voz alta` 2 行 |
| 英文 en | 4 | — | `AI Insights`、`Read aloud` 2 行 |
| 日文 ja | **6（全部）** | — | `✍ライティング`、`読み上げ` 均 2 行 |

**结论：这不是德/法语文案过长才触发的偶发问题——按钮盒模型对任何非 2 字文案都会换行、文字都会高出按钮框**（英文、日文同样中招）。用户观察到的德/法语严重是因为其文案天然更长。

### 3.2 设置页（实测无溢出）

德文/法文界面下对设置页 10 个 tab 的全部按钮/导航/ chips 逐个测量（`audit-data3.json`）：**0 处溢出**——设置页布局是自适应的，长文案会撑开容器而非溢出。

### 3.3 尚未测量的表面

popup 与引导页在 de/fr 下的按钮几何未测（popup 大量文案未适配 i18n，切换语言后仍是中文，测了也不能反映适配后的真实长度）；建议在问题 2 修复后随回归一并测量。
