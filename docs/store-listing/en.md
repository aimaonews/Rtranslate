## Name

Rtranslate - Bilingual Translation

## Summary (≤132 chars)

Open-source bilingual translation: multi-engine, local PII masking, wordbook & FSRS flashcards. No account, no telemetry.

## Detailed description

**Value proposition**

Read foreign-language pages as naturally as your native tongue. Rtranslate is a fully open-source bilingual translation extension: the original text stays visible with the translation right below it, preserving layout and links — and it works out of the box with free engines, no account required.

**Key features**

- **Bilingual page translation**: paragraph-by-paragraph original + translation; viewport-driven lazy translation to save quota; 13 display styles (soft gray, highlight, card, blur-mask self-test and more); one-click restore at any time
- **Every scenario**: selection bubble, hover paragraph translation, input-box translation (Alt+Enter), and document translation for 12 formats — PDF, EPUB, DOCX, PPTX, XLSX, HTML, JSON, TXT, Markdown, SRT/VTT/ASS — with bilingual export and post-editing
- **Video & meeting subtitles**: bilingual YouTube subtitles with smart ASR re-segmentation; click any subtitle word to look it up and save it; live caption translation for Google Meet / Teams / Zoom
- **Privacy first**: no account, no telemetry, no middle servers. Optional local PII masking — emails, phone numbers, bank cards, ID numbers and API keys are replaced with placeholders on your device before text is sent for translation, then restored locally. Sensitive data never leaves your browser
- **AI-powered**: OpenAI / DeepSeek / Claude / Gemini and any OpenAI-compatible endpoint; AI Experts (custom prompt strategies), AI terminology libraries (6 built-in domains + smart extraction), AI writing assistant, and Alt+D side-by-side multi-engine comparison
- **Language-learning loop**: one-click word saving with sentence context and source link, FSRS-spaced-repetition flashcard review, and on-page vocabulary highlighting
- **Privacy architecture**: API keys stored locally only; 10 interface languages; translation cache avoids repeat requests

**Supported translation services**

Free engines (Google / Microsoft / MyMemory with automatic failover), DeepL, OpenAI-compatible endpoints (OpenAI / DeepSeek / any compatible API), Claude, Gemini, self-hostable LibreTranslate, custom JSON endpoints, and AI Mao (our hosted service).
