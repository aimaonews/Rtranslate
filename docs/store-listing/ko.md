----- 여기부터 -----
외국어 페이지를 모국어처럼 편하게 읽어 보세요. Rtranslate는 오픈소스 이중언어 대조 확장 프로그램입니다. 원문 아래에 번역문을 문단별로 나란히 보여 주고, 페이지의 레이아웃과 링크는 그대로 유지합니다. 무료 엔진으로 바로 시작할 수 있으며 계정도 필요 없습니다.

✨ KEY FEATURES

✅ 이중언어 대조 보기: 원문과 번역문을 문단 단위로 표시. 화면에 보이는 부분만 처리해 리소스를 아끼고, 여러 표시 스타일 중에서 고를 수 있습니다
✅ 멀티 엔진: 자동 폴백이 있는 무료 엔진 외에 DeepL, OpenAI 호환 API, 자체 호스팅 가능한 LibreTranslate 등을 지원
✅ 문서 번역: PDF, ePub, DOCX, 자막 파일 등을 끌어다 놓아 처리하고, 대조본 또는 번역문만 내보낼 수 있습니다
✅ 영상·회의 자막: YouTube 이중언어 자막과 Meet / Teams / Zoom 실시간 자막을 지원합니다
✅ 로컬 마스킹: 이메일, 전화번호, 카드 번호, API 키 등을 보내기 전에 기기 안에서 플레이스홀더로 바꾸고, 결과가 돌아오면 복원합니다
✅ AI 전문가·용어집: 프롬프트 전략을 직접 정하고, 분야별 용어 라이브러리와 자동 추출로 전문 용어를 일관되게 처리
✅ 단어 플래시카드: 모르는 단어를 예문과 함께 저장하고 FSRS 간격 반복으로 복습. 페이지 하이라이트도 지원합니다
✅ Alt+D 비교 창: 여러 엔진의 결과를 나란히 비교해 문맥에 어울리는 표현을 고를 수 있습니다

🚀 HOW IT WORKS

1. 확장 프로그램을 설치하고 툴바 아이콘이나 Alt+T로 대조 보기를 켭니다.
2. 설정 페이지에서 엔진, 대상 언어, 번역문 스타일을 고릅니다. 기본값 그대로 시작해도 좋습니다.
3. 읽다가 모르는 단어를 저장하고, 틈날 때 플래시카드로 복습해 어휘를 늘려 보세요.

🔒 PRIVACY

설정, API 키, 단어장은 모두 브라우저 로컬 저장소에만 보관되며 텔레메트리는 없습니다. 마스킹을 켜면 개인정보는 기기를 떠나기 전에 플레이스홀더로 대체됩니다. 텍스트는 선택한 엔진에만 전송됩니다.
