看外文網頁像讀母語一樣自然。Rtranslate 是一款完全開源的雙語對照翻譯擴充功能：原文與譯文逐段並排呈現，排版與連結維持原樣。免費引擎開箱即用——無需註冊，無需帳號。

✨ KEY FEATURES【核心功能】

✅ 雙語對照——原文與譯文逐段並排，捲動到可見區域才翻譯，一鍵還原原文
✅ 多引擎——Google / 微軟 / MyMemory 免費鏈路失敗時自動切換，另支援 DeepL、OpenAI 相容端點、可自行架設的 LibreTranslate 與自訂 API
✅ 文件翻譯——PDF、EPUB、DOCX、HTML、Markdown、TXT 及 SRT/VTT/ASS 字幕，可匯出雙語對照或純譯文
✅ 影片字幕——YouTube 雙語字幕智慧斷句合併，線上會議即時字幕也能翻
✅ 隱私脫敏——電子郵件、電話、銀行卡、證件號、API 金鑰在傳送前於本機替換為佔位符，譯文回傳後於本機還原
✅ AI 專家與術語庫——自訂 Prompt 策略、內建領域術語庫與智慧擷取，譯名前後一致
✅ 生字閃卡——一鍵收藏生字並記錄原句出處，依 FSRS 間隔重複演算法排程複習，頁面上醒目標示
✅ Alt+D 對比窗——多個引擎的結果並排比對，擇優選用

🚀 HOW IT WORKS【上手三步】

1. 安裝後釘選到工具列，免費引擎立即可用。
2. 按一下圖示或按 Alt+T 翻譯整頁；選取文字即可喚出劃詞泡泡。
3. 需要更多時開啟設定：加入自己的 API 金鑰、挑選 AI 專家，或開啟脫敏。

🔒 PRIVACY【隱私保護】

無帳號、無遙測、無中間伺服器。設定與 API 金鑰只保存在瀏覽器的本機儲存空間。開啟脫敏後，敏感資料在本機替換為佔位符、譯文回傳後於本機還原——未脫敏的內容不會離開你的瀏覽器。
