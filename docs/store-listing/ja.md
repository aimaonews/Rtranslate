外国語のページを、母国語のように自然に読んでみませんか。Rtranslate はオープンソースの二か国語対訳拡張機能です。原文と訳文を段落ごとに並べて表示し、ページのレイアウトやリンクはそのまま保ちます。無料エンジンですぐに使い始められ、アカウント登録は不要です。

✨ KEY FEATURES

✅ 二か国語対訳表示：原文の下に訳文を段落単位で表示。画面に入った部分だけを処理する省リソース設計で、複数の表示スタイルから選べます
✅ マルチエンジン：自動フォールバック付きの無料エンジンに加え、DeepL、OpenAI 互換 API、自己ホスト可能な LibreTranslate などに対応
✅ ドキュメント翻訳：PDF、ePub、DOCX、字幕ファイルなどをドラッグ＆ドロップで処理し、対訳版または訳文のみで書き出せます
✅ 動画・会議字幕：YouTube の二か国語字幕や、Meet / Teams / Zoom のリアルタイム字幕に対応
✅ ローカル脱敏：メールアドレス、電話番号、カード番号、API キーなどを送信前に端末内でプレースホルダーへ置き換え、訳文の返却後に復元します
✅ AI エキスパートと用語集：プロンプト戦略をカスタムでき、分野別用語ライブラリと自動抽出で専門用語の訳し分けを統一
✅ 単語フラッシュカード：気になる単語を例文つきで保存し、FSRS 間隔反復で復習。ページ上でのハイライト表示にも対応
✅ Alt+D 比較ウィンドウ：複数エンジンの結果を並べて見比べ、文脈に合う訳を選べます

🚀 HOW IT WORKS

1. 拡張機能をインストールし、ツールバーのアイコンまたは Alt+T で対訳表示をオンにします。
2. 設定ページでエンジン、対象言語、訳文のスタイルを選択。初期設定のままでもすぐ使えます。
3. 読みながら単語を保存し、空き時間にフラッシュカードで復習して語彙を広げましょう。

🔒 PRIVACY

設定、API キー、単語帳はすべてブラウザのローカルストレージにのみ保存され、テレメトリーはありません。脱敏を有効にすれば、個人情報は端末から出る前にプレースホルダーへ置き換えられます。テキストの送信先は、選択したエンジンのみです。
