# Rtranslate — Chrome 应用商店详情页文案（简体中文）

## 名称（Name）

Rtranslate - 开源双语对照翻译

## 摘要（Summary，≤132 字符）

开源双语对照翻译：多引擎、本地脱敏、生词闪卡。无账号、无遥测。

## 详细描述（Detailed description）

**一句话价值主张**

看外文网页像读母语一样自然。Rtranslate 是一款完全开源的双语对照翻译扩展：原文在上、译文在下，保留原文排版与链接，免费引擎开箱即用，无需注册任何账号。

**核心功能**

- **整页双语对照翻译**：原文与译文逐段对照，滚动到可见区域才翻译以节省额度；13 种译文样式（柔和灰、高亮、卡片、模糊遮罩自测等）；随时一键恢复原文
- **全场景翻译**：划词翻译气泡、悬停段落翻译、输入框即时翻译（Alt+Enter）、网页内 PDF/EPUB/DOCX/PPTX/XLSX/字幕等 12 种文档格式翻译与双语导出
- **视频与会议字幕**：YouTube 双语字幕（自动断句合并），字幕单词点击查词并收藏；Google Meet / Teams / Zoom 会议实时字幕翻译
- **隐私优先**：无账号、无遥测、无中间服务器；可开启本地敏感信息脱敏——邮箱、电话、银行卡、证件号、API Key 在发送前于本机替换为占位符，译文返回后本地还原，敏感内容永不出浏览器
- **AI 加持**：支持 OpenAI / DeepSeek / Claude / Gemini 及任意 OpenAI 兼容端点；AI 专家（可自定义 Prompt 策略）、AI 术语库（6 大领域内置 + 智能提取）、AI 写作助手、Alt+D 多引擎并排对比
- **语言学习闭环**：网页与字幕生词一键收藏（自动记录原句与来源），FSRS 间隔重复算法闪卡复习，生词页面高亮
- **隐私架构**：API Key 仅存本机；10 种界面语言；翻译缓存免重复请求

**支持的翻译服务**

免费引擎（谷歌 / 微软 / MyMemory，失败自动切换）＋ DeepL ＋ OpenAI 兼容接口（OpenAI / DeepSeek / 任意兼容端点）＋ Claude ＋ Gemini ＋ LibreTranslate（可自托管）＋ 自定义接口＋ AI猫（本站服务）。
