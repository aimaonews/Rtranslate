看外文网页像读母语一样自然。Rtranslate 是一款完全开源的双语对照翻译扩展：原文与译文逐段并排呈现，排版与链接保持原样。免费引擎开箱即用——无需注册，无需账号。

✨ KEY FEATURES【核心功能】

✅ 双语对照——原文与译文逐段并排，滚动到可见区域才翻译，一键恢复原文
✅ 多引擎——谷歌 / 微软 / MyMemory 免费链路失败自动切换，另支持 DeepL、OpenAI 兼容接口、可自托管的 LibreTranslate 与自定义接口
✅ 文档翻译——PDF、EPUB、DOCX、HTML、Markdown、TXT 及 SRT/VTT/ASS 字幕，可导出双语对照或仅译文
✅ 视频字幕——YouTube 双语字幕智能断句合并，线上会议实时字幕也能翻
✅ 隐私脱敏——邮箱、电话、银行卡、证件号、API Key 在发送前于本机替换为占位符，译文返回后本地还原
✅ AI 专家与术语库——自定义 Prompt 策略、内置领域术语库与智能提取，译法前后一致
✅ 生词闪卡——一键收藏生词并记录原句出处，按 FSRS 间隔重复算法复习，页面上自动高亮
✅ Alt+D 对比窗——多个引擎的结果并排展示，择优选用

🚀 HOW IT WORKS【上手三步】

1. 安装后固定到工具栏，免费引擎立即可用。
2. 点击图标或按 Alt+T 翻译整页；划选文字可唤出气泡查词。
3. 需要更多时打开设置：添加自己的 API Key、挑选 AI 专家，或开启脱敏。

🔒 PRIVACY【隐私保护】

无账号、无遥测、无中间服务器。设置与 API Key 只保存在浏览器本地存储中。开启脱敏后，敏感信息在本机替换为占位符、译文返回后本地还原——未脱敏的内容不会离开你的浏览器。
